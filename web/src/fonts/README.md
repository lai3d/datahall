# Fonts

Barlow Semi Condensed, weights 500, 600 and 700, Latin subset, as served by Google Fonts (v16).
Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow), licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

Self-hosted so the page makes no request to another origin before it can paint. `style.css` declares the faces;
Vite gives the files hashed names under `/assets/`, which carry the immutable cache header from `vercel.json`.
